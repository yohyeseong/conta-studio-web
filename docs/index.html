1.1.0 DEVELOPMENT · 2026.10.02

더 명확하게 보고,
더 편하게 조정하세요.

  • 네 방향 아이소메트릭

    SE·SW·NE·NW 시점으로 모델을 확인합니다.

  • 용도별 레이어와 색상

    건물·녹지의 세부 용도를 펼치고, 노란 선택 테두리로 위치를 확인합니다.

  • 시작 가이드와 진행률

    화살표 안내 이미지, 다시 보지 않기 설정, 하단 진행 상태를 제공합니다.

  • 지도 시작 및 데이터 수신 개선

    시작 지도 중복 처리를 줄였습니다. 필요한 지역의 한국 OSM 자료를 서버에서 내려받고 PC 캐시로 재사용합니다.

위 내용은 1.1.0 개발본 기준입니다. 아래 RC24 경량 검증본에 포함되어 있으며 정식 안정판은 아닙니다.

GET STARTED

지도 선택부터 파일 저장까지

  1. 장소 검색·영역 선택

    장소를 검색하고 지도에서 오른쪽 마우스를 드래그해 범위를 지정합니다.

  2. 모델 생성

    생성 버튼을 누르고 하단 진행률을 확인합니다. 처리 중에는 중복 생성을 막습니다.

  3. 표시와 색상 조정

    레이어를 선택해 위치를 확인하고 색상 칸에서 색을 바꿉니다. 건물·녹지는 세부 용도별로 볼 수 있습니다.

  4. 내보내기

    Rhino / SketchUp 내보내기에서 형식과 저장 위치를 선택합니다.

RC24는 인터넷 연결이 필수입니다. 전국 자료를 설치 파일에 포함하지 않고 선택 지역만 서버에서 내려받습니다. 받은 자료는 PC 캐시에 저장해 재사용합니다.
현재 개발본의 SketchUp 출력은 교량의 고가 높이를 적용하지 않습니다. 비정상 메시가 제외된 구간에는 틈이 남을 수 있습니다. 공개 자료에 포함된 추정 높이·폭은 실측값과 다릅니다.
