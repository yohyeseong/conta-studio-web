레이어

02

생성하면 용도별 레이어가 표시됩니다.

파라펫은 설정한 높이와 두께 0.2m로 생성합니다. 원본 옥상 형태를 확인한 값은 아닙니다.

한 단 높이는 실제 지형의 m 단위입니다. 1m는 축척 1:1000에서 1mm입니다. 입력값은 다음 생성에 적용됩니다. 원본 높이·폭이 있으면 우선 사용합니다.

파일 저장

SketchUp은 실제 크기(1:1)로 저장합니다.
표시한 레이어의 색상·태그와 건물별 그룹을 유지합니다.
SketchUp 2017 이상에서 열 수 있습니다.

실제 크기는 축척 1:1로 저장하세요. 등고선은 선 객체로 저장됩니다.

Conta Studio 웹 사용 안내

1. 지도를 검색하거나 이동한 뒤 우클릭 드래그로 범위를 정합니다.

2. 콘타를 생성하고 마우스로 모델을 회전·확대합니다.

3. 레이어 표시와 색상을 조절하고 Rhino .3dm으로 저장합니다.

OSM에 군사시설로 표기된 대상과 관련 구역은 지도·생성에서 제외합니다. 미등록·오분류된 시설까지 식별하는 기능은 아닙니다. 기존 모델은 새 생성이 성공하면 교체됩니다. 건물은 원본 외곽선과 높이를 이용한 단순 입체이며 외벽 사진이나 세부 지붕은 포함하지 않습니다.

이 웹 버전은 지도 자동 생성과 NURBS 지형·건물 솔리드 저장을 지원합니다. SHP·DXF 불러오기는 Windows 버전을 이용해 주세요. 공개 데이터에 없는 높이·폭은 추정값이며 실측값이 아닙니다.

공식 도로는 2026-09-14 표준노드링크 중심선을 보강합니다. 실제 폭이 없는 구간은 설정한 기본 폭을 사용합니다. Copernicus GLO-30은 건물·수목이 포함된 표면 고도(DSM)이며 순수 지면 고도 자료가 아닙니다.
